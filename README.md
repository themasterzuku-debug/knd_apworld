Okay, for use of this APWorld, make sure to follow these instructions. 
Step 0. Ensure you have made a copy of the game for the Gamecube and that you have the Dolphin Emulator. 

Once that is setup, you will want to follow these next steps- 

Step 1. Download the newest Release of the knd_apworld (At this point in time, it is knd_apworld_v2 I believe? It may change in the future- But newest release) 
Step 2. Once Downloaded, Extract the Folder into your Archipelago > lib > worlds folder. Ensuring to use the Yaml to choose difficulty and set all of your settings as necessary. 
As well as moving the .apworld to the custom worlds folder in Archipelago as well. 
Step 3. the N1 Bank ISO bat to make a change to your currently downloaded rom to make it so that the Weapon Progression for N1 works as intended. That is VERY important. 
Ensure your Original ISO is elsewhere and that you made a copy of it to do this with. 
Step 4. From here, everything works as usual. Put Yaml in player folder, generate game, and set up server on Archipelago. 
Step 5. Turn on your game and get to the Title Screen. If you have played previously, start a new game first and play the intro cutscene. This is VERY important. 
Otherwise AP will recognize a last used Cutscene from a previous run, and auto-give an item. 
Step 6. Go into the Easy Client Folder and start up the Modular Dropper, as it connects to the server for AP AND opens Core Client as well. 
Step 7. If everything has been done correctly, you SHOULD be able to see that the order of the stages has been scrambled. That is good and means it worked. 
If you notice ANY issues while playing, please do not hesitate to let me know. You can also reach me on the KND page on Discord to let me know if there is any trouble or of any questions you may have.
